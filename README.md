# JustDraw 使用说明书

JustDraw 是一个给绘画练习使用的小工具。它可以随机切换参考图、做色块练习、从图片中取色，也可以把视频当作逐帧参考来翻看。

## 开始使用

双击 `JustDraw.exe` 启动软件。

第一次进入图片模式时，软件会自动弹出文件夹选择窗口；选择一个包含图片的文件夹后即可开始使用。第一次进入视频逐帧模式时，软件会自动弹出视频选择窗口。

支持的图片格式：`png`、`jpg`、`jpeg`、`bmp`、`gif`、`webp`。

支持的视频格式：`mp4`、`mov`、`mkv`、`avi`、`webm`、`m4v`、`wmv`、`flv`、`ts`、`mts`、`m2ts`。

## 基本操作

- `左方向键` 或 `PageUp`：上一张图片 / 上一帧
- `右方向键` 或 `PageDown`：下一张图片 / 下一帧
- `空格`：暂停或继续计时器
- `Ctrl + C`：复制当前显示的图片或视频帧
- 鼠标滚轮：缩放图片
- 按住鼠标左键拖动：移动图片
- 双击图片：重置当前图片视图
- 右键图片：打开常用操作菜单

## 模式

### 图片切换

用于参考图轮播和限时练习。

在 `文件` 菜单中选择图片文件夹后，可以使用左右方向键切换图片。打开 `随机播放` 后，切换时会随机选择图片。

计时器可以在 `计时器` 菜单中设置时长、重置、开启预倒计时和结束提醒。计时结束后的行为可以设为自动下一张、停在当前图片或开始超时计时。

### 色块练习

用于生成随机色块，练习颜色判断和概括。

可以在 `色感工具` 菜单中增加或减少颜色数量、刷新颜色、切换形状模式、设置最低亮度、最高亮度和最低饱和度。也可以复制当前颜色条。

在色块练习页面按住 `Ctrl` 并滚动鼠标滚轮，可以快速增加或减少颜色数量。

### 色彩照片

用于从参考图中练习色彩观察。

选择图片文件夹后，可以像图片切换模式一样浏览图片。开启 `采样 30 个图片颜色` 后，软件会从当前图片中提取颜色并显示色彩采样。

### 视频逐帧

用于把视频作为逐帧参考。

导入视频后，可以使用左右方向键逐帧切换，也可以使用 `随机帧` 跳到随机位置。快速切换时，当前帧编号会立即变化；如果目标帧还在缓冲，画面会暂时停在上一张已经加载好的帧，等目标帧准备好后再更新显示。

视频逐帧模式默认会缓存当前帧前后各 10 秒的画面。可以在 `设置` 菜单中调整缓冲秒数。

## 图片显示工具

在图片和视频逐帧模式中，可以使用这些显示工具：

- `马赛克`：给当前参考图或视频帧添加马赛克效果，并可用滑块无级调整尺寸
- `灰度显示`：把当前显示内容转为灰度
- 顶部栏 `视口` 菜单：可直接选择 `1:1`、`4:3`、`3:2`、`16:10`、`16:9`、`21:9`、`9:16`，也可以输入自定义宽高比
- `锁定图片视口比例`：窗口无论如何放大或缩小，图片显示区域都会保持已设置的比例
- 右键菜单中的水平翻转、垂直翻转、旋转、复制、在文件资源管理器中显示等操作

选择任一预设或自定义比例后会自动启用锁定；当前比例会显示在锁定项中，匹配的预设会显示勾选。视口比例与锁定状态是全局设置，会同时作用于图片切换、色彩照片和视频逐帧模式。

图片缩放、位置和旋转状态会按当前图片路径或视频路径保存，方便下次继续使用。

### 视口控制接口

`MainWindow` 实现了公开的 `IViewportController` 接口。调用 `SetViewportAspectRatio` 可以设置宽高比并立即启用锁定，调用 `SetViewportAspectRatioLock` 可以单独开关锁定：

```csharp
IViewportController viewport = mainWindow.ViewportController;
viewport.SetViewportAspectRatio(16, 9);
viewport.SetViewportAspectRatioLock(false);
```

设置的比例与锁定状态会保存到 JustDraw 状态文件，并同时作用于图片切换、色彩照片和视频逐帧模式。

## 主题和窗口

在 `设置` 菜单中可以：

- 开启或关闭窗口置顶
- 切换中文或英文界面
- 调整视频逐帧缓冲大小
- 修改主题色
- 检查更新

主题色会应用到菜单、选中标记、悬浮状态、弹出窗口边框等界面元素。

软件启动时会自动检查更新。若发现可用更新，`设置` 菜单会高亮提示；点击其中的更新入口即可下载并重启。检查更新会先尝试直连网络，直连失败后会自动使用系统代理。

JustDraw 免费开源发布在 GitHub 上，付费购买皆为骗局。如有建议或问题反馈，可以通过 `设置` 菜单中的 GitHub 仓库入口前往 issue 页面。

## 受保护视频导出

在 `窗口` 菜单中打开 `受保护视频导出`。

你可以添加一个或多个视频，设置目标秒数、水印文字或水印图片、输出格式，以及是否添加叠加层。导出成功后，文件会保存到原视频附近。

此功能需要电脑中可以使用 `ffmpeg` 和 `ffprobe`。如果缺少它们，软件会提示该功能不可用。

## 常见问题

### 打开后没有内容

如果没有自动弹出选择窗口，可以在 `文件` 菜单中手动选择图片文件夹，或在视频逐帧模式中导入视频。

### 视频逐帧切换时画面短暂停住

这是正常的缓冲行为。当前帧编号会继续跟随你的操作变化，画面会等目标帧加载完成后自动更新。

### 菜单栏不见了

开启 `窗口置顶` 后，顶部菜单会隐藏。可以在右键菜单中关闭窗口置顶。

### 无法使用视频逐帧或视频导出

请确认电脑中可以使用 `ffmpeg` 和 `ffprobe`。视频逐帧和受保护视频导出都依赖它们处理视频文件。

可以从这里下载 FFmpeg：<https://github.com/BtbN/FFmpeg-Builds/releases>

下载并解压后，可以在 PowerShell 中运行下面的命令，把解压目录里的 `bin` 添加到当前用户的系统 PATH：

```powershell
$root = Read-Host "请输入 FFmpeg 解压目录"; $bin = Join-Path $root "bin"; if (!(Test-Path (Join-Path $bin "ffmpeg.exe"))) { throw "没有找到 bin\ffmpeg.exe，请确认路径是 FFmpeg 的解压目录" }; $path = [Environment]::GetEnvironmentVariable("Path", "User"); if (($path -split ';') -notcontains $bin) { [Environment]::SetEnvironmentVariable("Path", ($path.TrimEnd(';') + ';' + $bin), "User") }; "已添加到用户 PATH，重新启动 JustDraw 后生效"
```
